# **App Name**: Home Stylist Portfolio

## Core Features:

- Horizontal Scrolling Hero: Implement a hero section with horizontally scrolling images.
- Smooth Scroll Navigation: Implement smooth scrolling navigation to different sections of the one-page website.
- About Section: Showcase Home Stylist as an interior design & full finishing studio in Sohag with a 4-step process.
- Service Grid: Display services in a grid of cards with icons, titles, and descriptions.
- Project Gallery: Showcase real interior design work using a grid of project cards.
- Contact Form: Include a form for users to book a free consultation and a WhatsApp button for quick contact.
- Sticky Header: Implement a sticky header with navigation links and a 'Book Consultation' button.

## Style Guidelines:

- Primary color: Navy Blue (#0F2442) for headings and key text, evoking a sense of trust and luxury.
- Background color: Off-White (#F1EFE9) for a calm and minimalist background.
- Accent color: Olive Green (#8CAA0E) and Terracotta (#C16C27) for buttons and small details, providing subtle visual interest.
- Headline font: 'Playfair' serif font for headings, providing a luxurious and high-end feel.
- Body font: 'PT Sans' sans-serif font for body text, ensuring readability and a modern touch. 
- Use minimalist line icons in olive green to represent services and process steps.
- Employ large white space to enhance the feeling of luxury and calm. Avoid clutter.
- Use soft shadows and rounded corners to create a modern, gentle aesthetic.
